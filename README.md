## 📱 Visão Geral da Plataforma

O **Natural FOOD** não é apenas uma vitrine digital, mas uma ferramenta corporativa completa simulando um ambiente de varejo real. O projeto foi desenvolvido focando na separação clara de responsabilidades entre Front-end e Back-end, garantindo escalabilidade e manutenção.

O grande diferencial competitvo desta plataforma é a sua **visão administrativa verticalizada**. Ela transcende o básico (cadastro de produtos) para gerenciar ativamente todo o ciclo de vida do pedido, desde a captura na web até a entrega final e feedback do cliente.

## ✨ Funcionalidades Chave

### 🛒 Portal do Cliente (Front-end)
*   **Vitrine Inteligente:** Exibição dinâmica de produtos com filtros avançados.
*   **Carrinho de Compras:** Gestão de itens em tempo real com persistência.
*   **Checkout One-Page:** Experiência de pagamento simplificada e segura.
*   **Área do Cliente:** Histórico de pedidos e rastreio.

### ⚙️ Painel Administrativo (Gestão Completa)
*   **Gestão de Estoque:** Controle granular de entradas, saídas e alertas de estoque baixo.
*   **Esteira Logística:** Gerenciamento visual do status do pedido (Pendente > Em Preparo > Expedido > Entregue).
*   **NPS (Net Promoter Score):** Sistema integrado de feedback pós-venda para medir a satisfação do cliente.
*   **Relatórios Gerenciais:** Análise de vendas e performance de produtos.

## 🛠️ Stack Tecnológico

A plataforma utiliza tecnologias modernas e de mercado para simular um ambiente corporativo robusto.

*   **Front-end:** React.js, Next.js, Vue.js
*   **Back-end (API):** Java
*   **Banco de Dados:** PostgreSQL, MongoDB
